## Sobre las Notas de Clase

Las notas se redactan en LaTeX y se compilan aparte; aquí sólo se distribuye el PDF resultante.
El documento está **en proceso permanente de mejora**, de modo que conviene descargar la versión
más reciente en lugar de trabajar con una copia guardada.

La correspondencia entre cada capítulo de las notas, la unidad del temario y la carpeta de código
que le toca está en el [README principal](../README.md).
